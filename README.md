# Charles Gomes, vidraceiro

Site de uma página para a vidraçaria do Charles Gomes: serviços, galeria de trabalhos reais e pedido de orçamento pelo WhatsApp.

- `index.html`: página completa (HTML, CSS e JS num arquivo só)
- `img/`: fotos dos trabalhos (JPG redimensionado)
- `charles.jpg`: foto do Charles

O número do WhatsApp fica na variável `WHATSAPP` no final do `index.html`.
